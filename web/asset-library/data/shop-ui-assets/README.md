# Оригинальные детали магазина Sega Dune USA

Это извлечённый исходный пиксель-арт, без увеличения, перерисовки и генерации.
Каждый PNG связан с native-снимком и sourceRect в manifest.json.

Воспроизведение из корня dune-original-web:

```sh
clang -std=c11 -O1 tools/extract_shop_ui.c -o .local/extract-shop-ui -lm
mkdir -p .local/shop-ui-raw
.local/extract-shop-ui ../dune-web/data/evidence/mission-atreides-01.cpu.bin .local/shop-ui-raw
python3 tools/extract_shop_ui.py .local/shop-ui-raw data/shop-ui-assets
```

`frames` — оригинальные кадры и те же кадры без подвижной красной рамки.
`buttons` — реально наблюдённые состояния команд. `selection` — отдельно исходная
рамка с прозрачностью по native 4bpp sprite indices. `panels`, `icons`, `chrome` —
непрозрачные исходные детали с родным фоном. Чёрный цвет не превращался в прозрачный.

Для растягиваемой панели сохранены 8×8 образцы исходных углов, краёв и заполнения.
Это исходные образцы, а не обещание бесшовной растяжки любого корпуса: их стыки
нужно проверять при новой компоновке. Полные кадры позволяют сравнить результат.

Это не полный набор всех возможных команд и состояний всей кампании. Изображения
самих зданий и их анимации находятся в отдельной выгрузке. Файлы остаются локальными;
публичное распространение здесь не выполнялось.
