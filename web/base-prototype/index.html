Шесть рядов по три ячейки сохраняют родной порядок базы. Под значками нет ценников; цена выбранной постройки показана в информационной панели. Если высоты мало, список прокручивается колёсиком или перетаскиванием, без случайного выбора.

Корпус собран из родных деталей с цельными скруглениями. Экран и название соединены оригинальной рамкой; прямые края удлиняются без растягивания углов. Буквы, цифры и значки — исходные.

Красная рамка пульсирует по родным четырём фазам. Лампы проигрывают записанную последовательность оригинального экрана.
