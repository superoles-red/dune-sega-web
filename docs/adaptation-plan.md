# Полная адаптация интерфейса Sega USA

Задание: перенести принятый модульный стиль базы в настоящую игру, сделать
доступными все здания и остальные экраны, заменить парольный ввод выбором
миссий. Сохранить оригинальные сценарии, AI, цены, производство, победу/поражение,
единичное выделение, баланс и боевые часы.

Перед началом сохранён архив рабочей версии:
`.local/checkpoints/before-full-adaptation-20261102-210757/working-project.tar.gz`.
Старый слот браузера `dune-original-aot-state-v2` сохраняется при миграции.

- [x] Живой C-мост зданий: все фабрики, Palace, Starport, Upgrade, ремонт,
  недоступные команды, цены/наличие и графика из текущего родного кадра.
- [x] Настоящие HTML-кнопки поверх аккуратного нативного корпуса; принятая
  компоновка, шесть рядов, прокрутка и предварительный выбор перед покупкой.
- [x] Все остальные экраны: титул, дома, карта кампании, брифинг, результаты,
  финалы, настройки/пауза и подтверждения. Крупные кнопки из родных PNG и Back.
- [x] Выбор дома → девять миссий. Пароли остаются только декоративными именами.
  У каждого дома отдельные открытые/пройденные миссии и сохранение активной игры.
- [x] Новая миссия открывается только по нативному событию победы; повторное
  прохождение старых не уменьшает открытый прогресс. Поражение не открывает этап.
- [x] Проверки нативных процедур и исходных байтов ROM/инструкций, покупок,
  сохранений, победы/поражения; браузерные проверки обоих положений и переходов.

Распределение: building_assets — живые меню/графика юнитов;
focus_verification — сценарии, переходы и исходы; shop_ui_assets — остальные
родные экраны/детали; root — компоновка, настоящие кнопки, сохранения и интеграция.

Родные процедуры определяют доступность и результаты действий. Мост передаёт
пользовательское намерение; UI не выдаёт здания, деньги или боевые приказы сам.
Новые оболочки не публикуются во внешние сервисы в рамках этого задания.
План измерения тяжёлого боя остаётся в `performance-plan.md`: ускорение симуляции
и снятие оригинальных ограничений без отдельной проверки не допускаются.

## Итог проверки

Интерфейс подключён к игре на `/`, отдельный прототип сохранён. Отчёты:
`full-adaptation-qa.md` (нативные адаптеры), `native-campaign-bridge.md` и
`data/campaign/verification.json` (кампания), `full-adaptation-browser-qa.md`
(браузер). Снимки before-outcome созданы с контролируемыми офлайн-условиями;
это проверка исходного события победы, а не прохождение кампании игроком.
