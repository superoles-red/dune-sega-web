# Историческая ссылка: выбор и действия

Актуальное описание находится в [native-actions.md](native-actions.md).
Управление оболочки описано в [controls.md](controls.md).

Ранее этот файл описывал эксперимент с группами, рамкой и рассылкой приказов.
Этот вариант удалён из текущего управления. Его API, проверки групп и прежние
трактовки состояния юнита не являются описанием нынешней реализации.

Сейчас адаптер использует одиночный выбор, отдельное снятие выделения,
контекстную исходную B и перетаскивание готовой постройки. Исходные действия,
проверки и точные границы native-доказательств приведены в новом документе.
