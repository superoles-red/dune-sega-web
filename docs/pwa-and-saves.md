# Полный экран, установка, офлайн и файлы сохранений

[Открыть игру](https://superoles-red.github.io/dune-sega-web/)

Эти функции принадлежат веб-оболочке. Они не меняют правила боя, цены,
подкрепления, сбор спайса, карты или исходный ход игрового времени.

## Полный экран и значок

Для полного экрана нажмите маленький значок слева сверху. Это единственная
кнопка полного экрана, доступная и внутри зданий. Кнопка игровой паузы `MENU`
на карте расположена сразу справа от этого значка. Полноэкранный режим включается по нажатию
пользователя, если браузер поддерживает его для игр. Выход —
той же кнопкой или системным жестом/Escape. Масштаб камеры внутри игры — отдельная
функция и не заменяет полный экран браузера.

- **iPhone:** откройте сайт в Safari → «Поделиться» → «На экран Домой» → оставьте
  «Открывать как веб-приложение» включённым, если есть такой переключатель.
  Запускайте игру с нового значка. Панелей Safari не будет; системные области
  iOS, вырез и домашний индикатор учитываются компоновкой. Обычная вкладка Safari
  на iPhone не обязана поддерживать полноэкранную кнопку для canvas.
- **Android:** откройте `OPTIONS`/паузу → `FILES & OFFLINE` → `INSTALL GAME`, если браузер предложит установку,
  или меню браузера → «Установить приложение» / «На главный экран».
- **ПК:** можно играть во вкладке и включить полный экран значком слева сверху. Chrome/Edge
  также могут предложить установку. В Safari на Mac доступно «Добавить в Dock».

Наличие значка и готовность офлайн-копии — разные вещи. Для игры без сети
выполните следующий шаг.

## Подготовить игру без интернета

1. При доступном интернете откройте `OPTIONS`/паузу → `FILES & OFFLINE` → `PREPARE OFFLINE`.
2. Дождитесь сообщения о завершении загрузки всех файлов. До него загрузка
   может быть неполной.
3. Закройте игру и запустите её со значка или той же ссылки. При следующем
   запуске готовая офлайн-копия получит управление; после этого можно играть без сети.

Локально сохраняются необходимые файлы этой версии: интерфейс, native-движок,
графика, звуковой вывод, оба языка и справочник. Встроенные в ядро сценарии
и ресурсы не требуют отдельного игрового сервера. Браузер может потребовать
первое пользовательское касание для включения звука.

Офлайн-обновление устанавливается целиком; неуспешная загрузка новой версии
не должна удалять предыдущую готовую копию. Работающая миссия не переключается
на другой набор файлов посреди игры. При повторном запуске с сетью можно
подготовить новую версию. Защищённое браузерное хранение запрашивается там,
где доступно; окончательное решение остаётся за браузером.

Удаление данных сайта или самого приложения может удалить офлайн-копию и
браузерные сейвы. Поэтому важный прогресс лучше дополнительно сохранить файлом.
Не используйте приватную вкладку для длительного прохождения.

## Сохранить файл

Откройте `OPTIONS`/паузу → `FILES & OFFLINE` → `DOWNLOAD SAVE`. Получится один небольшой файл,
содержащий:

- один общий слот Continue с состоянием активной кампании, если он есть;
- открытые и пройденные миссии каждого из трёх домов;
- выбранный язык и сведения о формате/совместимости.

Графика и звуковые ресурсы в файл не дублируются. Техническая демонстрация
не подменяет сохранение кампании.

На ПК файл скачивается в Downloads или другую выбранную папку. На iPhone
используйте открывшееся системное меню «Поделиться» → «Сохранить в Файлы»;
при необходимости выберите iCloud Drive. Если обмен файлами недоступен,
используется обычная загрузка браузера. На Android — Downloads либо другое
доступное место. Системный диалог зависит от браузера.
Игра не получает неограниченного доступа к папкам и не переписывает файл
автоматически в фоне.

Обычный автосейв продолжает храниться в этом браузере. Скачанный файл — отдельная
резервная копия на момент экспорта, которая не обновляется вслед за ним.

## Восстановить или перенести

1. Откройте игру на нужном устройстве/в нужном браузере.
2. Откройте `OPTIONS`/паузу → `FILES & OFFLINE` → `LOAD SAVE FILE` и укажите ранее скачанный файл.
3. Проверьте сведения и подтвердите замену текущего сохранения и прогресса.
4. Сохранённая миссия возобновится сразу. Если архив содержит только открытые
   миссии без активного Continue, откроется главное меню.

Повреждённый, слишком большой, неподходящий по версии или посторонний файл
не должен менять текущие данные. При отказе браузера записать данные импорт
сообщает об ошибке. Сейвы сторонних ремейков/эмуляторов не считаются этим форматом.
Не переименовывайте произвольный файл в сохранение игры.

Автоматической синхронизации между Safari, Chrome, другими устройствами или
отдельно установленными экземплярами нет. Не рассчитывайте, что данные вкладки
и значка на Home Screen всегда общие: используйте экспорт/импорт для переноса.

## Исходники и постоянный адрес

`SOURCE CODE` в `FILES & OFFLINE` открывает публичный GitHub-репозиторий. Его
можно клонировать или скачать ZIP; исходники native-ядра, инструменты и инструкции
сборки также опубликованы. Репозиторий и ZIP не входят в обязательную загрузку
игры или офлайн-кеш. Обычные обновления сохраняют origin самой игры, чтобы
данные её браузерного хранилища оставались привязаны к прежнему адресу.

## English quick guide

Use the single upper-left icon for fullscreen; the map's **Menu** button is
immediately to its right. The fullscreen icon remains available inside buildings.
Open **Options/Pause →
Files & Offline** for **Download Save**, **Load Save File**, **Install
Game**, **Prepare Offline**, and **Source Code**. On iPhone, use Safari → Share → Add to Home Screen → Open as Web
App, then launch the icon. On Android/desktop, use the browser's supported
installation/fullscreen controls. A Home Screen icon alone does not guarantee
offline readiness: wait until offline preparation finishes, then relaunch the game.

Browser autosaves stay local to that browser/profile. Export a save file for an
independent backup; it contains the global Continue slot, each house's mission
progress, and language. Import it on another device or after clearing browser
data and review the confirmation. An archived active mission resumes immediately;
a progress-only archive returns to the main menu. Exported files are snapshots,
not automatic cloud synchronization. Original game mechanics are unchanged.
