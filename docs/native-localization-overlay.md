# Русские подписи поверх исходного кадра

Механика, ROM, RAM, стек, счётчики и последовательность исходных сцен не меняются. Локализация использует отдельную копию последнего завершённого VDP-кадра. Под удалёнными буквами восстанавливаются живые plane B/sprites с текущими палитрой и прокруткой. Чёрные прямоугольники, статическая подложка и пересчёт результатов не используются.

## Результаты

`_dune_web_results_frame_rgb()` возвращает исходный RGB320×224 с удалёнными только клетками английских подписей и звания. `_dune_web_results_overlay_json()` возвращает `ready`, `frame`, `labelMask`, `labelInk`, `rankInk`, `rankVisible`, `rank`. Оба вызова выполняются синхронно для одного завершённого кадра.

Двенадцать подписей определяются по исходным tile02F5..030B/palette3. Их прямоугольники:

| Бит | Исходная подпись | x,y,w,h |
|---|---|---|
|0|SCORE:|24,24,48,8|
|1|TIME:|200,24,40,8|
|2|YOU HAVE ATTAINED THE RANK OF|48,40,232,8|
|3|SPICE HARVESTED BY|88,88,144,8|
|4|UNITS DESTROYED BY|88,128,144,8|
|5|STRUCTURES DESTROYED BY|72,168,184,8|
|6,8,10|YOU:|48,104/144/184,32,8|
|7,9,11|ENEMY:|32,112/152/192,48,8|

Звание читается из настоящих bank0500+ASCII клеток строки y56, в том числе до окончания подсчёта. Белая краска подписей берётся из завершённой CRAM61, жёлтая краска звания из CRAM40. Счёт/время и все шесть числовых областей остаются исходным RGB. Режим исключён из `password_scroll`: хозяин интерфейса может удержать последний локализованный кадр на собственном переходе.

`drawLocalizedResults(ctx,art,state,{width:320,height:224,overlay})` в `web/localized-results.mjs` рисует только переведённые подписи и настоящее звание. `art.displayText()` переводит строку, `art.text(...,{ink,shadow:true,transparent:true})` использует исходную геометрию шрифта и текущий цвет.

## Финал и титры

`_dune_web_localized_scene_frame_rgb()` и `_dune_web_localized_scene_overlay_json()` действуют только в `ending`/`credits`. Метаданные содержат `lines:[{text,x,y,width,ink}]`, с настоящей прокруткой, включая отрицательный y и частично видимую нижнюю строку. `drawLocalizedSceneLabels()` рисует эти строки поверх полученного RGB.

Подтверждён первичный текст ROM USA0x11932..0x11E34. Используется bank0480+ASCII; controlFF02 выбирает palette2 для должностей, FF03 — palette3 для имён и The End. Цвет каждой строки определяется по её исходной name-table entry и foreground nibbleD. Заменяются только 15 точных строк:

`The End`, `Executive producer`, `Producers`, `Product Coordinators`, `Designers`, `Programmers`, `Writer`, `Artists`, `Music and Sound`, `Voices`, `Frank Klepacki - House voices`, `Glenn Sperry - Units`, `Quality Assurance`, `Special thanks to`, `Thank you for playing`.

Имена авторов, марки, логотипы и правовые уведомления остаются исходными; две строки голосов переводят только описание, сохраняя имена. Фон планеты и все прочие слои не меняются.

## Проверка

```sh
clang -std=c11 -O1 tools/test_localized_results_native.c -o .local/test-localized-results-native -lm
.local/test-localized-results-native .local/campaign-scenes/house1-mission01-victory.cpu.bin .local/campaign-scenes/house1-ending.cpu.bin
node --test tests/localized-results.test.mjs
```

В естественной последовательности advisor→Results проверены638 завершённых кадров,354 кадра с числовыми клетками,222 кадра с ранним исходным званием и148 кадров исходной прокрутки к паролю. Все шесть ненулевых счётчиков дополнительно проверены с явно контролируемыми offline аргументами настоящей функции271E2; это тестовые входные данные, не изменение игрового runtime. Каждый числовой пиксель и весь CPU остаются идентичны до/после read-only вызовов.

В двух исходных потоках белая краска подписей имела один наблюдавшийся уровень255. Отдельная контролируемая матрица исходного VDP-рендера проверяет все8 аппаратных уровней белого/жёлтого; это не объявляется наблюдением восьмифазного затемнения в естественном потоке.

Для окончания/титров проверены2167 завершённых исходных кадров,1713 кадров с подписями, все15 строк и238 наблюдений частично обрезанных строк. Пиксели имён, правовых уведомлений и рисунка вне разрешённых строк остаются побайтно исходными.

## Остальная видимая английская графика

В проверенных исходных victory/defeat movie reference-кадрах текстовых надписей нет: это рисунок и анимация. Проверка отдельных кадров не доказывает отсутствие текста во всех возможных промежуточных состояниях. Сюжетные строки обрабатываются отдельным каталогом111 реплик/254 предложений.

Внутри зданий надо переводить `producer.name`, `detailTexts.name` (в том числе Upgrade/Out Of Stock/Send Order), а не повторно рисовать исходный английский crop имени. EXIT/FIX/STOP имеют отдельные подлинные русские PNG. Названия объектов и14 действий доступны в языковом каталоге. На карте краткий исходный статус `OK` — отдельная графика постройки; это не сюжетная строка. Оригинальные голоса/музыка не заменялись русской записью.
